# 年輪 ANNULA — Grow with spirit.

商業空間綠意解決方案官網原型（單一自包含 HTML 檔，內嵌字型與圖片，無需建置流程即可直接開啟）。

## 內容

- `index.html` — 完整網站（首頁、精選商品、綠意空間訂閱、綠植到府整理、關於年輪、LINE 下單流程模擬）
- `Product/` — 精選商品照片素材
- `PLANT RENTAL/` — 自由搭配訂閱商品照片素材

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何套件或啟動伺服器。

## 部署

這是靜態網站，可直接部署到 GitHub Pages、Netlify、Vercel 等靜態主機服務。
