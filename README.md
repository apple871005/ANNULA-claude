# 年輪 ANNULA — Grow with spirit.

商業空間綠意解決方案官網原型（單一自包含 HTML 檔，內嵌字型與圖片，無需建置流程即可直接開啟）。

## 內容

- `index.html` — 完整網站（首頁、精選商品、綠意空間訂閱、綠植到府整理、關於年輪、LINE 下單流程模擬）
- `Product/` — 精選商品照片素材
- `PLANT RENTAL/` — 自由搭配訂閱商品照片素材

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何套件或啟動伺服器。

## 部署

這是靜態網站，可直接部署到 GitHub Pages、Netlify、Vercel 等靜態主機服務。

## AI 空間規劃小幫手（原型，開發中）

`plan.html` 是一個實驗性功能：使用者上傳空間照片，取得建議植栽清單與報價試算。這個功能需要呼叫 Gemini API，因此需要一個小型 Node 伺服器來保護 API 金鑰（金鑰不可出現在瀏覽器端）。

- 植栽分析與報價已串接真實 Gemini API；合成預覽圖改用本機去背 PNG 疊圖（不需 AI 圖像 API 的帳單額度，永久免費）。
- 尚未加進主要導覽列，只能透過網址直接開啟。
- 詳見 [`server/README.md`](server/README.md) 了解如何本機啟動。
